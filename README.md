# 声线实验室 · Voice Lab

说一句话，分析它的音高、共振、音质和节奏。

支持两个方向：**MtF（女性化）** 和 **FtM（男性化）**，在首页切换，参照数据与文案随之改变。

**所有分析在浏览器里完成**，录音不上传、不存服务器、不调用任何在线 AI。页面加载完之后，DevTools 的 Network 面板不会再有任何请求。

## 看什么

- **音高**：说话 F0 中位数，对照成人女声 165–255 Hz / 成人男声 100–150 Hz
- **共振**：声道长度（VTL）估算，女声 13–16 cm / 男声 16.5–19.5 cm
- **音高与共振是否同步**：FtM 尤其关键——睾酮会降低音高，但基本不改变声道长度
- **音质与节奏**：CPP、语速、停顿

## 隐私

不申请、不使用任何网络接口。录音只存在于当次浏览器内存，分析完即丢弃；历史记录只保存三个数字，存在 localStorage。

唯一的外链是 GitHub 仓库——只有你主动点爱心或反馈按钮时才会跳转，页面本身不会发起任何请求。网页没有权限替你在 GitHub 上点 Star，那需要登录授权，所以爱心只负责把你带到仓库。

## 说明

参考区间来自公开的成人嗓音研究，是人群统计范围，**不是诊断标准**。

- 男声说话 F0：Cao & Lei (2017), *J Forensic Sci Med* 3(4):217-222，100 名普通话青年男性，朗读 128.4 Hz / 自由说话 122.4 Hz，77% 落在 100–140 Hz
- 持续元音 F0 均值：Meng et al., WESPAC IX 2006
- 女声说话 F0 目前只有通用范围，无同等依据，可信度低于男声

VTL 为估算值，误差约 ±1.5 cm。

本工具不提供医疗建议，不评价性别认同。若出现疼痛、持续嘶哑，请停止并咨询言语治疗师。
